## あらすじ

2023年、Mnet『BOYS PLANET』。93人の参加者から、デビュー枠9席（ZEROBASEONE）を懸けたサバイバルが始まる。
主人公（なお・21歳目前）は日本人参加者のサポートスタッフ（通訳補助・現地コーディネート）として帯同し、井汲大翔と三度目の再会を果たす。
日プ36位、創造営15位――そして史実のボイプラでは21位で散った彼の運命を、裏側のサポートで覆し、9位以内でのデビューを目指すIF物語。
