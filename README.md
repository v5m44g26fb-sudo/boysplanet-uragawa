# 担当をデビューさせる件

三部作の第3作。『PRODUCE 101 JAPAN』（日プ編）、『創造営2021』（創造営編）に続く、スマホ風SNSゲーム。

- プレイ用URL: https://v5m44g26fb-sudo.github.io/boysplanet-uragawa/
- ローカル正本: `~/workspace/boysplanet-uragawa/`（単一 `index.html` ＋ `assets/`）

## あらすじ

2023年、Mnet『BOYS PLANET』。93人の参加者から、デビュー枠9席（ZEROBASEONE）を懸けたサバイバルが始まる。
主人公（なお・21歳目前）は日本人参加者のサポートスタッフ（通訳補助・現地コーディネート）として帯同し、井汲大翔と三度目の再会を果たす。
日プ36位、創造営15位――そして史実のボイプラでは21位で散った彼の運命を、裏側のサポートで覆し、9位以内でのデビューを目指すIF物語。

## v1.2の更新（磨き込みパス）
- タイトル画面を新設し、公式KV寄せに作り込み：公式ロゴの字形（丸みのある極太ゴシック2段組＋四芒星）を再現、惑星リング＋星空のKV文法、公式プロフィール写真の円形チップ配置、Mnet Plus公式の惹句「あなたの心を動かす全世界98人の少年たちがやって来る！」、放送情報バンド（Mnetロゴマーク色＋「2023年2月2日（木）夜8時 初放送・毎週木曜・ABEMAでも日韓同時配信」）。出典：Mnet Plus公式番組ページ、公式コンセプトポスター（Here I am版）、PR TIMES（Mnet Japan）。「はじめから／つづきから」はセーブ有無で表示切替、はじめからは既存セーブがある場合のみ確認のうえ消去。短い画面高ではロゴ・チップが段階的に縮小し、ボタンが欠けないことを実測確認

- Twitter検索を実検索化：キーワードでツイートとユーザーを実際に絞り込み（検索中は入力フォーカスを維持）。トレンドをタップするとそのキーワードで検索。
- Twitterプロフィールの「返信」「メディア」タブに実コンテンツ：返信は既存ツイートを返信先の文脈付きで表示、メディアは既存の公式写真（Instagram投稿で使用済みのCAST写真）を対応付けたグリッド表示。DMは空状態のまま。
- ニュース詳細の「戻る」を、正規の名前付きハンドラ（nwBack）に組み替え（従来は生成HTMLの onclick を後から同期上書きする脆い構造だった）。動作仕様は不変。
- Instagramのいいね件数を数値データ化し、いいねトグルで件数も±1連動（表示は桁区切り数値に変更）。
- LINE：メッセージごとに時刻を表示（データに時刻がないため、スレッド内容から決定的に算出する方式。自分の吹き出しは既読＋時刻、相手は吹き出し右下に時刻）。トーク背景色を、LINEデフォルトテーマの空色として同シリーズの実物寄せ検証値 #8CABD8 に寄せた（従来は独自値 #7494b8）。
- 新規ボイス2本を組み込み：line4「2スター……。ここから、上げていきます」（0:03）をスターレベルテスト後のチーム大阪トークへ、line3「明日、発表ですね。……大丈夫です。なおさんが、ついててくれるんで」（0:05）を発表前夜の通話へ。通話字幕内のボイス吹き出しは、タップしても字幕が進まないようにし、次の台詞へ進むと再生を止める。
- 物語の文章追加は、上記の提供済みボイス2本に伴う分のみ（line3は通話台詞として追加、line4はトーク内のボイスメッセージとして追加）。それ以外の新規セリフ追加はなし。

## v1の収録範囲（第1部）

プロローグ（三度目の再会）→ スターレベルテスト（チーム大阪「Zero For Conduct」）→ シグナルソングテスト（「Here I Am」）→ 裏側サポート配分 ×2フェーズ → K対Gグループバトル（「VERY NICE」）→ 発表前夜の通話 → 第1回生存者発表式まで。

- 大翔以外の順位・ポイント・スター評価は公表値（出典：Wikipedia『BOYS PLANET』）を使用。大翔の第1回順位はプレイ内容（選択＋サポート配分）で変動し、標準プレイで史実どおり21位（1,381,864点）付近、良いプレイで12位前後まで届く調整。
- フリーチャットは付けていない（シリーズ方針）。

## データ・素材について

- 史実データ: Wikipedia『BOYS PLANET』（日英）で裏取り。第1回発表は52名分の順位・ポイント実数を収録。全93名の名簿（名前・読み・グループ・所属・生年月日・スター評価）も収録し、裏取りできない項目は推測で埋めていない。
- 写真: Mnet公式プロフィール写真30名分（主要キャスト）。KProfiles掲載分から取得し、ファイル名で同一性を確認のうえ連絡先シートで目視確認済み。それ以外は別人回避のためイニシャル表示。
- 音楽: iTunes公式プレビュー30秒（BOYS PLANET「난 빛나 (Here I Am)」／SEVENTEEN「VERY NICE」）、順位発表BGMは Kevin MacLeod「The Descent」（CC-BY）。
- ボイス: 井汲大翔ボイス（AnyVoice生成）4本を組み込み済み（再会 0:05／バトル後 0:07／発表前夜の通話 0:05／スターレベルテスト後 0:03）。原音は `new-voices/` に保管。
- 時代考証: 2023年当時の実物寄せ（iPhone 14 Pro世代・iOS 16、LINE現行緑、SNSは「X」ではなくTwitter、投票アプリ「Mnet Plus」を実装）。
